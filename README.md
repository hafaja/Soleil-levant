# Soleil Levant SARL – sitio web

Sitio estático (ES/FR) publicado con GitHub Pages.

- `index.html` – página principal
- `aviso-legal.html` / `avis-legal.html` – Aviso legal / Mentions légales
- `politica-privacidad.html` / `politique-confidentialite.html` – Privacidad / Confidentialité
- `assets/css/legal.css` – estilos de las páginas legales
- `images/` – imágenes ilustrativas

Publicar: Settings › Pages › Deploy from a branch › `main` / `(root)`.
